# Simple Python Payment Gateway – Polymorphism Challenge

## Description
A Python program demonstrating polymorphism by processing different payment methods through a single checkout function.

## Payment Methods
- **CreditCard** – Processes credit card payments.
- **DigitalWallet** – Routes payments through a digital wallet.

## Expected Output
```text
Processing a credit card payment of $500
Routing $300 through digital wallet
Processing a credit card payment of $200
```

## OOP Concepts
- Inheritance
- Polymorphism
- Method Overriding
